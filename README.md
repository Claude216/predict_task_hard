## Overview

This repository investigates what **meta-features** (a.k.a. *cheap surface features*) of a dataset influence — or help predict — the performance of an **active learner (AL)**.

## Research Question

> What dataset-level meta-features predict active learner performance, and can they be used to guide learner or configuration selection in advance?
